# Valko Research Project

Independent research, fact-checking, and data analysis related to the Valko / Ao Yin controversy in *Love and Deepspace*.

This repository is being redesigned as a public-facing research space. The goal is to organize verifiable information, distinguish findings from hypotheses, and make complex fandom developments easier to inspect without exposing individual users unnecessarily.

## What I work on

- Public-source research and fact-checking
- Timeline reconstruction and source verification
- Fandom discourse analysis
- Data cleaning, structuring, and visualization
- Research archive / evidence architecture
- Methods for separating findings, hypotheses, questions, and sources

## Tools

I mainly use:

- **R** for statistical analysis and data exploration
- **Python** for data processing, research automation, and prototyping
- HTML / CSS for lightweight public reports and interfaces
- GitHub for versioning, documentation, and reproducible research workflows

## Public-data policy

The public version of this project is being rebuilt with stronger privacy and research-ethics safeguards.

Public materials should avoid unnecessary account-level identification and should prioritize:

- anonymized or aggregated presentation where possible
- clear separation between verified facts and interpretation
- traceable source provenance
- transparent uncertainty and revision history

Detailed working notes, raw evidence, and account-level verification records are not intended to be exposed in the public-facing layer.

## Current direction

I am developing a more structured research archive for the Valko issue, with an emphasis on reproducibility, source quality, and readable visualization rather than simple document dumps.

This is an independent fan research project and is not affiliated with Infold Games or Papergames.
